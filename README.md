# SHTORM

VPN-клиент: вставил ссылку подписки — нажал кнопку — подключился.

- **Android** — полноценный VPN на весь телефон
- **Windows** — через системный прокси (запускается без прав администратора)
- Протокол: VLESS (Xray). Ссылка подписки берётся с твоей панели (Remnawave и т.п.)

## Как получить APK и exe (без установки чего-либо на компьютер)

1. Зарегистрируйся на https://github.com
2. Создай новый репозиторий (**Public**, имя любое, например `shtorm`)
3. Загрузи туда всё содержимое этой папки: `Add file → Upload files`,
   перетащи папки `lib`, `.github` и файлы `pubspec.yaml`, `README.md`.
   Если `.github` не видно в проводнике — включи показ скрытых папок.
4. Открой вкладку **Actions** → слева **Build SHTORM** → **Run workflow**
5. Через 15–30 минут внутри запуска появятся файлы внизу страницы (Artifacts):
   - `SHTORM-android-apk` — распакуй и установи `app-release.apk` на телефон
   - `SHTORM-windows` — распакуй zip в любую папку и запусти `shtorm.exe`

## Если сборка упала

Открой упавший запуск, скопируй красный текст ошибки и покажи его мне — поправлю.

## Что внутри

- `lib/main.dart` — интерфейс
- `lib/subscription.dart` — загрузка и разбор ссылки подписки
- `lib/vpn_service.dart` — подключение (Android и Windows)
- `lib/xray_config.dart` — конфиг Xray из ссылки vless://
- `.github/workflows/build.yml` — автосборка

## Важно

- Внутри приложения нет серверов и ключей: у каждого пользователя своя ссылка подписки.
- Приложение не проверялось сборкой на устройствах: первая сборка может потребовать правок.
- Лицензии используемых компонентов (Xray, flutter_v2ray) проверь перед публичным запуском.
